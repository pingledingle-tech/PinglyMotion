PinglyMotion for Claude (extension)

This lets Claude pose, play, look at and save animations in PinglyMotion.

1. Nothing else has to be installed: the Claude app brings the Node it needs.
2. Start PinglyMotion, click the AI Assistant button in its status bar and turn it on. It is off at every start.
3. Ask Claude, for example: "Raise the avatar's right arm and show me a picture."

Claude talks to PinglyMotion only on this computer. A screenshot of the 3D view is sent to Claude.
Claude can only open and save animations in the PinglyMotion folder in your Documents folder.
Nothing secret is stored in this extension.

Update: install the new PinglyMotion.mcpb from the new PinglyMotion download the same way
(Claude app: Settings > Desktop app > Manage next to Extensions > Advanced settings > Install Extension...).
More: https://github.com/pingledingle-tech/PinglyMotion/blob/main/docs/CONTROL.md
