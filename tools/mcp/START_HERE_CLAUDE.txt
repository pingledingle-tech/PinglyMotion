PinglyMotion with Claude: 4 steps
=================================

You need the Claude app (Claude Desktop) for Windows. Python is not needed.

1. Unzip this download first (right-click the zip > Extract All).
   Do not open PinglyMotion.mcpb from inside the zip.

2. Add the extension in the Claude app (this works on every PC):
   a. Start the Claude app and open Settings.
   b. Open Extensions. (In newer versions: Settings > Desktop app,
      then click Manage next to Extensions.)
   c. Click Advanced settings. Find the section Extension Developer
      and click Install Extension...
   d. In the file window, go to the unzipped folder and pick
      PinglyMotion.mcpb.
   e. The Claude app shows a window about the extension "PinglyMotion".
      Read it and follow the prompts to finish (click the install or
      confirm button it shows).
   You should see PinglyMotion in the list of extensions, switched on.
   Instead of c and d you can also drag PinglyMotion.mcpb into the
   Claude window. Double-clicking the file may also work, but if
   Windows asks which app to use, ignore that and use the steps above.
   If your Claude account belongs to a company or team, the
   administrator may have blocked your own extensions. Then say so.

3. Start PinglyMotion.exe. In its menu click
   Options > Allow remote control (AI and other programs).
   There is a tick before it when it is on. It is off at every start,
   so do this each time you start PinglyMotion.

4. In the Claude app, start a new chat and type:
   Raise the avatar's right arm and show me a picture.
   Claude may ask for permission to use PinglyMotion. If it does,
   allow it. If it does not ask, that is fine too. The arm moves in
   PinglyMotion and Claude shows you a picture.

If Claude says it cannot reach PinglyMotion: check that PinglyMotion is
running and step 3 is ticked, then try again.

If it does not work, write down at which step and what you saw
(a picture of the Claude window is enough).

More: docs/CONTROL.md in the repository, section "Set up an AI assistant".
