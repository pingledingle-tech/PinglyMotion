## What

UX direction, part E (beginner animation view): in Beginner mode the 3D view gets most of the window, the Joints list is closed by default (one visible button and the View menu bring it back), the finger grid and Edit curve stay behind the Expert switch (one visible button turns it on), the Selected joint panel and the timeline with Set key stay. Expert mode keeps today's layout. Each mode remembers its own layout.
