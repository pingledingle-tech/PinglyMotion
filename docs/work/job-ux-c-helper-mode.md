## What

Job UX-C, helper mode (new UX direction of 24 Nov 2026, issue 74): one Helper switch at the top of
the main window. Off: a clean tool. On: one helper panel floating beside the tool with the hint
cards and a few short lessons; each lesson step points at the real control with a highlight and
goes on when the user does it.
