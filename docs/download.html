Download PinglyMotion

PinglyMotion 0.1 is an early preview. It is made for trying out and for feedback: expect rough edges and changes.

The first pre-release is still being prepared. If the releases page does not show a version yet, it has not been published yet.

Open the releases page

Which file?

Windows (64-bit)

A zip file. Extract it to a folder of your choice and start PinglyMotion.exe. Keep the data folder next to it.

Linux (x86_64)

An AppImage file. Make it executable (chmod +x) and start it.

Both need a graphics driver with OpenGL 3.3. Every release also has a SHA256SUMS file for checking your download.

Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Windows downloads are signed with free code signing provided by SignPath.io, certificate by SignPath Foundation, once the application is approved. Until then, Windows downloads are not signed and Windows may warn about an unknown publisher.

Read the Code signing policy and the privacy policy.

Uninstall and system changes

  • Windows: there is no installer. Delete the folder you extracted the zip file into. That removes the program.
  • Linux: delete the AppImage file.
  • PinglyMotion does not change your system configuration. The program does not use the Windows registry (its settings are a plain file), does not add startup entries and does not install services or drivers.

What the program writes on your computer, besides the files you save:

  • Settings, as a plain file in your user settings folder: %APPDATA%\PinglyMotion on Windows, ~/.config/PinglyMotion on Linux.
  • The local error log, the connection file of the local remote control and saved skeleton maps, in the PinglyMotion folder of your user data folder: %LOCALAPPDATA%\PinglyMotion on Windows, ~/.local/share/PinglyMotion on Linux. See the privacy policy.
  • If you use an AI assistant with the remote control, its work folder is Documents/PinglyMotion.

To remove every trace, delete the program as above and then these folders.
