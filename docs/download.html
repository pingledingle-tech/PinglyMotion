Download PinglyMotion

PinglyMotion 0.3.0-beta.2 is an early preview (a prerelease on GitHub). It is made for trying out and for feedback: expect rough edges and changes.

PinglyMotion is a beta: an early preview made as a hobby project. It is for trying out. Expect bugs, and save your work often. A script and an animation have been tried in Second Life. Script Lab runs scripts on your own computer only. A script that works in Script Lab may behave differently in Second Life, and the other way round. Using PinglyMotion is free; uploading an animation to Second Life costs a small fee, charged by Second Life.

The Windows zip, the Linux AppImage and the checksum file are on the release page.

Download for Windows (zip)

Download for Linux (AppImage)

Windows may warn. This early preview is not code-signed, so Windows may show ‘Windows protected your PC’ or ‘unknown publisher’. That is expected. Only continue if you downloaded the file from this release page. Choose ‘More info’, then ‘Run anyway’.

Check your download (optional but recommended).

  1. On the release page, also download the file SHA256SUMS.
  2. In Windows PowerShell, go to the folder with your download and run: Get-FileHash <file name>. On Linux run: sha256sum <file name>.
  3. The long number must match the line for your file in SHA256SUMS. This shows that your download is complete and unchanged.

The checksum file sits on the same page as the download, so it cannot protect you if that page were tampered with. For that, each file also has a signed build record that shows which source code it was built from. If you use the GitHub command line tool: gh attestation verify <file name> --repo pingledingle-tech/PinglyMotion.

Linux: if the AppImage does not start, your system may need the library ‘libfuse2’.

There is no version for macOS and none for ARM processors.

Release notes and all files

Which file?

Windows (64-bit)

A zip file. Extract it to a folder of your choice and start PinglyMotion.exe. Keep the data folder next to it.

Linux (x86_64)

An AppImage file. Make it executable (chmod +x) and start it.

Both need a graphics driver with OpenGL 3.3. Every release also has a SHA256SUMS file for checking your download.

PinglyMotion does not yet tell you when a new beta is out. Look at the release page now and then. Only the latest release gets fixes.

PinglyMotion is free software. You may use, study, share and change it under the GNU General Public License, version 2 or later. It carries other people’s work under their own licences, for example the Qt toolkit, avatar bodies, motion clips and example scripts. The full list with each licence is in CREDITS.md.

Uninstall and system changes

  • Windows: there is no installer. Delete the folder you extracted the zip file into. That removes the program.
  • Linux: delete the AppImage file.
  • PinglyMotion does not change your system configuration. The program does not use the Windows registry (its settings are a plain file), does not add startup entries and does not install services or drivers.

What the program writes on your computer, besides the files you save:

  • Settings, as a plain file in your user settings folder: %APPDATA%\PinglyMotion on Windows, ~/.config/PinglyMotion on Linux.
  • The local error log, the connection file of the local remote control and saved skeleton maps, in the PinglyMotion folder of your user data folder: %LOCALAPPDATA%\PinglyMotion on Windows, ~/.local/share/PinglyMotion on Linux. See the privacy policy.
  • If you use an AI assistant with the remote control, its work folder is Documents/PinglyMotion.

To remove every trace, delete the program as above and then these folders.

PinglyMotion is an independent project. It is not made, endorsed or supported by Linden Research, Inc. (Linden Lab). Second Life and Linden Lab are trademarks of Linden Research, Inc. Firestorm, Aurora, OpenCollar and other names belong to their owners.
