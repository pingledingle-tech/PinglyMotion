Privacy policy

Short version: The program collects no personal data and sends no telemetry. It works offline; the one exception is the update check described below. The project’s GitHub pages keep what GitHub keeps: for example the public account names of people who write issues, and visitors’ IP addresses in GitHub’s logs.

The program

  • No personal data, no telemetry. PinglyMotion has no usage statistics, advertising or tracking, and it sends nothing about you or your animations anywhere.
  • It works offline. Opening, editing and saving animations needs no internet connection.
  • Update check. The only network use of the program itself is the update check. About once a week, when it starts, it asks GitHub's public API (api.github.com) for the version number of the latest release and compares it with the installed version. The request contains the program name and version number. GitHub also sees your IP address, as with any web request. You can switch the check off in the About dialog (automatic updates). It is switched on by default. At the moment it cannot find beta versions, so it will not tell you about a new beta. Look at the release page now and then.
  • Local connections only. The remote control interface for AI assistants and the live link to Aurora use only your own computer (127.0.0.1). What an assistant that you connect does with what it sees is governed by that assistant's provider, not by PinglyMotion.
  • AI Assistant (optional, off at every start). If you connect an AI app, it can see what PinglyMotion shows it: poses, pictures of the 3D view, script text and folder names. The AI app may send that to its own company. That company’s privacy rules apply. PinglyMotion itself sends nothing to any AI company. Turning the AI Assistant off locks every AI out.
  • Local error log. A log file (pinglymotion.log) stays on your computer. It is at most 5 MB, your home folder is replaced by a placeholder in it, and it is never sent anywhere. Help > Open log shows it, Help > Clear log empties it.
  • Settings (for example window layout and the update setting) are stored on your computer only. Script Lab examples you make are in Documents/PinglyMotion/Scripts. If you use the setup button for the ChatGPT desktop app, PinglyMotion edits that app’s configuration file (a copy of the old file is kept).

The optional text-to-motion helper

The helper in the repository (tools/kimodo) is not part of the program or of the downloads. Only when you set it up yourself, it downloads packages and model files from public sources: the uv installer from PyPI, PyTorch from download.pytorch.org, the Kimodo code from GitHub and the models from Hugging Face. It needs your own free Hugging Face account and a read token that you enter yourself. The token is kept in the helper's folder on your computer, is used only to talk to Hugging Face and can be deleted with forget-token. The sentence you type to describe a motion is processed on your own computer. These services have their own privacy policies.

This website

  • No cookies, no tracking, no analytics, no advertising. The pages load no fonts, scripts or images from other sites.
  • Your language choice and your light or dark choice are saved in your browser's local storage on your own device (pinglymotion-lang and pinglymotion-theme). They are never sent to anyone. Clear the site data of your browser to remove them.
  • The clickable mockup page also remembers some of your choices in your browser (names that start with pm-mockup-). They are never sent anywhere.
  • The website is hosted by GitHub Pages. GitHub may process visitor data such as IP addresses in its server logs; see GitHub's privacy statement.

GitHub

The repository, issues and pull requests are on GitHub and are public. Do not write personal details there (names, account names, email addresses, or screenshots that show them). GitHub's privacy statement applies to your GitHub account.

GDPR and contact

The project aims to follow the GDPR. Its approach is data minimisation: it collects nothing, so there is no personal data on the project's side to access, correct or delete.

Who is responsible. Pingledingle (the GitHub account pingledingle-tech) is responsible for this website and project. Private contact for privacy questions: send a private message on GitHub. Please do not post personal details in public issues.

Personvernerklæring

Kort fortalt: Programmet samler ikke inn personopplysninger og sender ingen telemetri. Det fungerer uten nett; unntaket er oppdateringssjekken som er beskrevet nedenfor. Prosjektets GitHub-sider beholder det GitHub beholder: for eksempel de offentlige kontonavnene til folk som skriver saker (issues), og besøkendes IP-adresser i GitHubs logger.

Programmet

  • Ingen personopplysninger, ingen telemetri. PinglyMotion har ingen bruksstatistikk, reklame eller sporing, og sender ingenting om deg eller animasjonene dine noe sted.
  • Det fungerer uten nett. Å åpne, redigere og lagre animasjoner krever ingen internettforbindelse.
  • Oppdateringssjekk. Det eneste programmet selv bruker nettet til, er oppdateringssjekken. Omtrent en gang i uken, ved oppstart, spør det GitHubs offentlige API (api.github.com) om versjonsnummeret til den nyeste utgivelsen og sammenligner det med den installerte versjonen. Forespørselen inneholder programnavnet og versjonsnummeret. GitHub ser også IP-adressen din, som ved enhver nettforespørsel. Du kan slå sjekken av i Om-dialogen (automatiske oppdateringer). Den er slått på som standard. Foreløpig finner den ikke beta-versjoner, så den sier ikke fra om en ny beta. Se på utgivelsessiden nå og da.
  • Bare lokale forbindelser. Fjernstyringsgrensesnittet for KI-assistenter og live-koblingen til Aurora bruker bare din egen datamaskin (127.0.0.1). Hva en assistent du kobler til gjør med det den ser, bestemmes av assistentens leverandør, ikke av PinglyMotion.
  • AI Assistant (valgfritt, av ved hver oppstart). Hvis du kobler til en KI-app, kan den se det PinglyMotion viser den: positurer, bilder av 3D-visningen, skripttekst og mappenavn. KI-appen kan sende det videre til sitt eget selskap. Selskapets personvernregler gjelder. PinglyMotion selv sender ingenting til noe KI-selskap. Når du slår AI Assistant av, er alle KI-er låst ute.
  • Lokal feillogg. En loggfil (pinglymotion.log) blir på datamaskinen din. Den er høyst 5 MB, hjemmemappen din er erstattet med en plassholder i den, og den sendes aldri noe sted. Hjelp > Open log viser den, Hjelp > Clear log tømmer den.
  • Innstillinger (for eksempel vindusoppsett og oppdateringsvalget) lagres bare på datamaskinen din. Script Lab-eksempler du lager, ligger i Documents/PinglyMotion/Scripts. Hvis du bruker oppsettknappen for ChatGPT-skrivebordsappen, endrer PinglyMotion den appens konfigurasjonsfil (en kopi av den gamle filen blir beholdt).

GitHub

De repository, issues en pull requests staan op GitHub en zijn openbaar. Schrijf daar geen persoonlijke gegevens (namen, accountnamen, e-mailadressen of schermafbeeldingen waarop die te zien zijn). Voor je GitHub-account geldt de privacyverklaring van GitHub.

AVG en contact

Het project streeft ernaar de AVG te volgen. De aanpak is dataminimalisatie: het verzamelt niets, dus er zijn bij het project geen persoonsgegevens om in te zien, te corrigeren of te verwijderen.

Wie verantwoordelijk is. Pingledingle (het GitHub-account pingledingle-tech) is verantwoordelijk voor deze website en dit project. Privécontact voor privacyvragen: een privébericht op GitHub. Plaats geen persoonlijke gegevens in openbare issues.

PinglyMotion is een onafhankelijk project. Het is niet gemaakt, goedgekeurd of ondersteund door Linden Research, Inc. (Linden Lab). Second Life en Linden Lab zijn handelsmerken van Linden Research, Inc. Firestorm, Aurora, OpenCollar en andere namen zijn van hun eigenaren.
