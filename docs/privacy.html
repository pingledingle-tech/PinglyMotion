Privacy policy

Short version: PinglyMotion collects no personal data and sends no telemetry. It works offline.

Last updated: 22 November 2026.

The program

  • No personal data, no telemetry. PinglyMotion has no usage statistics, advertising or tracking, and it sends nothing about you or your animations anywhere.
  • It works offline. Opening, editing and saving animations needs no internet connection.
  • Update check. The only network use of the program itself is the update check. About once a week, when it starts, it asks GitHub's public API (api.github.com) for the version number of the latest release and compares it with the installed version. The request contains the program name and version number. GitHub also sees your IP address, as with any web request. You can switch the check off in the About dialog (automatic updates).
  • Local connections only. The remote control interface for AI assistants and the live link to Aurora use only your own computer (127.0.0.1). What an assistant that you connect does with what it sees is governed by that assistant's provider, not by PinglyMotion.
  • Local error log. A log file (pinglymotion.log) stays on your computer. It is at most 5 MB, your home folder is replaced by a placeholder in it, and it is never sent anywhere. Help > Open log shows it, Help > Clear log empties it.
  • Settings (for example window layout and the update setting) are stored on your computer only.

The optional text-to-motion helper

The helper in the repository (tools/kimodo) is not part of the program or of the downloads. Only when you set it up yourself, it downloads packages and model files from public sources: the uv installer from PyPI, PyTorch from download.pytorch.org, the Kimodo code from GitHub and the models from Hugging Face. It needs your own free Hugging Face account and a read token that you enter yourself. The token is kept in the helper's folder on your computer, is used only to talk to Hugging Face and can be deleted with forget-token. The sentence you type to describe a motion is processed on your own computer. These services have their own privacy policies.

This website

  • No cookies, no tracking, no analytics, no advertising. The pages load no fonts, scripts or images from other sites.
  • Your language choice and your light or dark choice are saved in your browser's local storage on your own device (pinglymotion-lang and pinglymotion-theme). They are never sent to anyone. Clear the site data of your browser to remove them.
  • The website is hosted by GitHub Pages. GitHub may process visitor data such as IP addresses in its server logs; see GitHub's privacy statement.

GitHub

The repository, issues and pull requests are on GitHub and are public. Do not write personal details there (names, account names, email addresses, or screenshots that show them). GitHub's privacy statement applies to your GitHub account.

GDPR and contact

The project aims to follow the GDPR. Its approach is data minimisation: it collects nothing, so there is no personal data on the project's side to access, correct or delete. For questions about privacy, open an issue on GitHub. Issues are public, so ask without personal details.

Personvernerklæring

Kort fortalt: PinglyMotion samler ikke inn personopplysninger og sender ingen telemetri. Programmet fungerer uten nett.

Sist oppdatert: 22. november 2026.

Programmet

  • Ingen personopplysninger, ingen telemetri. PinglyMotion har ingen bruksstatistikk, reklame eller sporing, og sender ingenting om deg eller animasjonene dine noe sted.
  • Det fungerer uten nett. Å åpne, redigere og lagre animasjoner krever ingen internettforbindelse.
  • Oppdateringssjekk. Det eneste programmet selv bruker nettet til, er oppdateringssjekken. Omtrent en gang i uken, ved oppstart, spør det GitHubs offentlige API (api.github.com) om versjonsnummeret til den nyeste utgivelsen og sammenligner det med den installerte versjonen. Forespørselen inneholder programnavnet og versjonsnummeret. GitHub ser også IP-adressen din, som ved enhver nettforespørsel. Du kan slå sjekken av i Om-dialogen (automatiske oppdateringer).
  • Bare lokale forbindelser. Fjernstyringsgrensesnittet for KI-assistenter og live-koblingen til Aurora bruker bare din egen datamaskin (127.0.0.1). Hva en assistent du kobler til gjør med det den ser, bestemmes av assistentens leverandør, ikke av PinglyMotion.
  • Lokal feillogg. En loggfil (pinglymotion.log) blir på datamaskinen din. Den er høyst 5 MB, hjemmemappen din er erstattet med en plassholder i den, og den sendes aldri noe sted. Hjelp > Open log viser den, Hjelp > Clear log tømmer den.
  • Innstillinger (for eksempel vindusoppsett og oppdateringsvalget) lagres bare på datamaskinen din.

Den valgfrie hjelperen for tekst til bevegelse

Hjelperen i repoet (tools/kimodo) er ikke en del av programmet eller av nedlastingene. Bare når du selv setter den opp, laster den ned pakker og modellfiler fra offentlige kilder: installasjonsprogrammet uv fra PyPI, PyTorch fra download.pytorch.org, Kimodo-koden fra GitHub og modellene fra Hugging Face. Den trenger din egen gratis Hugging Face-konto og en lesetoken som du skriver inn selv. Token lagres i hjelperens mappe på datamaskinen din, brukes bare til å snakke med Hugging Face og kan slettes med forget-token. Setningen du skriver for å beskrive en bevegelse, behandles på din egen datamaskin. Disse tjenestene har egne personvernerklæringer.

Dette nettstedet

  • Ingen infokapsler, ingen sporing, ingen analyse, ingen reklame. Sidene laster ikke skrifter, skript eller bilder fra andre nettsteder.
  • Språkvalget ditt og valget av lys eller mørk drakt lagres i nettleserens lokale lagring på din egen enhet (pinglymotion-lang og pinglymotion-theme). De sendes aldri til noen. Slett nettstedsdata i nettleseren for å fjerne dem.
  • Nettstedet ligger på GitHub Pages. GitHub kan behandle besøksdata som IP-adresser i sine tjenerlogger; se GitHubs personvernerklæring.

GitHub

Repoet, sakene (issues) og pull requests ligger på GitHub og er offentlige. Ikke skriv personopplysninger der (navn, kontonavn, e-postadresser eller skjermbilder som viser dem). GitHubs personvernerklæring gjelder for GitHub-kontoen din.

GDPR og kontakt

Prosjektet har som mål å følge GDPR. Tilnærmingen er dataminimering: det samler ikke inn noe, så det finnes ingen personopplysninger hos prosjektet som kan gis innsyn i, rettes eller slettes. Spørsmål om personvern kan du stille ved å opprette en sak på GitHub. Saker er offentlige, så spør uten personopplysninger.

Datenschutzerklärung

Kurz gesagt: PinglyMotion erhebt keine personenbezogenen Daten und sendet keine Telemetrie. Es funktioniert offline.

Zuletzt aktualisiert: 22. November 2026.

Das Programm

  • Keine personenbezogenen Daten, keine Telemetrie. PinglyMotion hat keine Nutzungsstatistik, keine Werbung und kein Tracking und sendet nichts über dich oder deine Animationen irgendwohin.
  • Es funktioniert offline. Animationen öffnen, bearbeiten und speichern braucht keine Internetverbindung.
  • Update-Prüfung. Die einzige Netzwerknutzung des Programms selbst ist die Update-Prüfung. Etwa einmal pro Woche fragt es beim Start die öffentliche GitHub-API (api.github.com) nach der Versionsnummer der neuesten Veröffentlichung und vergleicht sie mit der installierten Version. Die Anfrage enthält Programmname und Versionsnummer. GitHub sieht außerdem deine IP-Adresse, wie bei jeder Webanfrage. Du kannst die Prüfung im Info-Dialog ausschalten (automatische Updates).
  • Nur lokale Verbindungen. Die Fernsteuerung für KI-Assistenten und die Live-Verbindung zu Aurora nutzen nur deinen eigenen Computer (127.0.0.1). Was ein Assistent, den du anbindest, mit dem Gesehenen macht, bestimmt der Anbieter des Assistenten, nicht PinglyMotion.
  • Lokales Fehlerprotokoll. Eine Protokolldatei (pinglymotion.log) bleibt auf deinem Computer. Sie ist höchstens 5 MB groß, dein Home-Ordner wird darin durch einen Platzhalter ersetzt, und sie wird nirgendwohin gesendet. Help > Open log zeigt sie, Help > Clear log leert sie.
  • Einstellungen (zum Beispiel Fensteranordnung und die Update-Einstellung) werden nur auf deinem Computer gespeichert.

Der optionale Helfer für Text zu Bewegung

Der Helfer im Repository (tools/kimodo) gehört weder zum Programm noch zu den Downloads. Nur wenn du ihn selbst einrichtest, lädt er Pakete und Modelldateien aus öffentlichen Quellen herunter: den uv-Installer von PyPI, PyTorch von download.pytorch.org, den Kimodo-Code von GitHub und die Modelle von Hugging Face. Er braucht dein eigenes kostenloses Hugging-Face-Konto und ein Lese-Token, das du selbst eingibst. Das Token liegt im Ordner des Helfers auf deinem Computer, wird nur für die Kommunikation mit Hugging Face verwendet und lässt sich mit forget-token löschen. Der Satz, mit dem du eine Bewegung beschreibst, wird auf deinem eigenen Computer verarbeitet. Diese Dienste haben eigene Datenschutzerklärungen.

Diese Website

  • Keine Cookies, kein Tracking, keine Analyse, keine Werbung. Die Seiten laden keine Schriften, Skripte oder Bilder von anderen Seiten.
  • Deine Sprachwahl und deine Wahl zwischen hellem und dunklem Farbschema werden im lokalen Speicher deines Browsers auf deinem eigenen Gerät gespeichert (pinglymotion-lang und pinglymotion-theme). Sie werden nie an jemanden gesendet. Lösche die Websitedaten deines Browsers, um sie zu entfernen.
  • Die Website wird über GitHub Pages bereitgestellt. GitHub kann Besucherdaten wie IP-Adressen in seinen Server-Protokollen verarbeiten; siehe die Datenschutzerklärung von GitHub.

GitHub

Repository, Issues und Pull Requests liegen auf GitHub und sind öffentlich. Schreibe dort keine persönlichen Angaben (Namen, Kontonamen, E-Mail-Adressen oder Screenshots, die sie zeigen). Für dein GitHub-Konto gilt die Datenschutzerklärung von GitHub.

DSGVO und Kontakt

Das Projekt will die DSGVO einhalten. Der Ansatz ist Datenminimierung: Es erhebt nichts, also gibt es auf Seiten des Projekts keine personenbezogenen Daten, die man einsehen, berichtigen oder löschen könnte. Bei Fragen zum Datenschutz eröffne ein Issue auf GitHub. Issues sind öffentlich, frage also ohne persönliche Angaben.

Polityka prywatności

W skrócie: PinglyMotion nie zbiera danych osobowych i nie wysyła telemetrii. Działa offline.

Ostatnia aktualizacja: 22 listopada 2026.

Program

  • Brak danych osobowych, brak telemetrii. PinglyMotion nie ma statystyk użycia, reklam ani śledzenia i nigdzie nie wysyła niczego o Tobie ani o Twoich animacjach.
  • Działa offline. Otwieranie, edycja i zapis animacji nie wymagają połączenia z internetem.
  • Sprawdzanie aktualizacji. Jedyne użycie sieci przez sam program to sprawdzanie aktualizacji. Mniej więcej raz w tygodniu, przy starcie, pyta publiczne API GitHuba (api.github.com) o numer wersji najnowszego wydania i porównuje go z zainstalowaną wersją. Zapytanie zawiera nazwę programu i numer wersji. GitHub widzi też Twój adres IP, jak przy każdym zapytaniu internetowym. Sprawdzanie można wyłączyć w oknie „O programie” (automatyczne aktualizacje).
  • Tylko połączenia lokalne. Interfejs zdalnego sterowania dla asystentów AI i połączenie na żywo z Aurorą używają tylko Twojego komputera (127.0.0.1). To, co podłączony przez Ciebie asystent robi z tym, co widzi, zależy od dostawcy tego asystenta, a nie od PinglyMotion.
  • Lokalny dziennik błędów. Plik dziennika (pinglymotion.log) pozostaje na Twoim komputerze. Ma najwyżej 5 MB, Twój folder domowy jest w nim zastąpiony symbolem zastępczym i nigdy nie jest nigdzie wysyłany. Help > Open log go pokazuje, Help > Clear log go czyści.
  • Ustawienia (na przykład układ okien i ustawienie aktualizacji) są zapisywane tylko na Twoim komputerze.

Opcjonalny pomocnik „tekst na ruch”

Pomocnik w repozytorium (tools/kimodo) nie jest częścią programu ani plików do pobrania. Tylko gdy sam go skonfigurujesz, pobiera pakiety i pliki modeli z publicznych źródeł: instalator uv z PyPI, PyTorch z download.pytorch.org, kod Kimodo z GitHuba i modele z Hugging Face. Potrzebuje Twojego własnego darmowego konta Hugging Face i tokenu do odczytu, który wpisujesz samodzielnie. Token jest przechowywany w folderze pomocnika na Twoim komputerze, służy tylko do komunikacji z Hugging Face i można go usunąć poleceniem forget-token. Zdanie, którym opisujesz ruch, jest przetwarzane na Twoim własnym komputerze. Te usługi mają własne polityki prywatności.

Ta strona internetowa

  • Bez plików cookie, bez śledzenia, bez analityki, bez reklam. Strony nie ładują czcionek, skryptów ani obrazów z innych witryn.
  • Wybór języka oraz jasnego lub ciemnego motywu jest zapisywany w pamięci lokalnej przeglądarki na Twoim własnym urządzeniu (pinglymotion-lang i pinglymotion-theme). Nigdy nie jest nikomu wysyłany. Aby je usunąć, wyczyść dane witryn w przeglądarce.
  • Strona jest hostowana przez GitHub Pages. GitHub może przetwarzać dane odwiedzających, takie jak adresy IP, w swoich logach serwerów; zobacz politykę prywatności GitHuba.

GitHub

Repozytorium, zgłoszenia (issues) i pull requesty są na GitHubie i są publiczne. Nie wpisuj tam danych osobowych (imion i nazwisk, nazw kont, adresów e-mail ani zrzutów ekranu, które je pokazują). Do Twojego konta GitHub stosuje się polityka prywatności GitHuba.

RODO i kontakt

Projekt dąży do zgodności z RODO. Jego podejście to minimalizacja danych: nic nie zbiera, więc po stronie projektu nie ma danych osobowych do wglądu, poprawienia ani usunięcia. W sprawach prywatności otwórz zgłoszenie na GitHubie. Zgłoszenia są publiczne, więc pytaj bez danych osobowych.

Privacybeleid

Kort gezegd: PinglyMotion verzamelt geen persoonsgegevens en stuurt geen telemetrie. Het werkt offline.

Laatst bijgewerkt: 22 november 2026.

Het programma

  • Geen persoonsgegevens, geen telemetrie. PinglyMotion heeft geen gebruiksstatistieken, reclame of tracking en stuurt niets over jou of je animaties ergens naartoe.
  • Het werkt offline. Animaties openen, bewerken en opslaan vraagt geen internetverbinding.
  • Updatecontrole. Het enige netwerkgebruik van het programma zelf is de updatecontrole. Ongeveer één keer per week vraagt het bij het starten de openbare API van GitHub (api.github.com) om het versienummer van de nieuwste release en vergelijkt dat met de geïnstalleerde versie. Het verzoek bevat de programmanaam en het versienummer. GitHub ziet ook je IP-adres, zoals bij elk webverzoek. Je kunt de controle uitzetten in het Info-venster (automatische updates).
  • Alleen lokale verbindingen. De afstandsbediening voor AI-assistenten en de live-koppeling met Aurora gebruiken alleen je eigen computer (127.0.0.1). Wat een assistent die je koppelt met wat hij ziet doet, wordt bepaald door de aanbieder van die assistent, niet door PinglyMotion.
  • Lokaal foutenlogboek. Een logbestand (pinglymotion.log) blijft op je computer. Het is hooguit 5 MB, je thuismap is erin vervangen door een plaatsaanduiding en het wordt nooit ergens naartoe gestuurd. Help > Open log toont het, Help > Clear log maakt het leeg.
  • Instellingen (bijvoorbeeld de vensterindeling en de update-instelling) worden alleen op je computer opgeslagen.

De optionele helper voor tekst naar beweging

De helper in de repository (tools/kimodo) is geen onderdeel van het programma of van de downloads. Alleen als je hem zelf instelt, downloadt hij pakketten en modelbestanden van openbare bronnen: het installatieprogramma uv van PyPI, PyTorch van download.pytorch.org, de Kimodo-code van GitHub en de modellen van Hugging Face. Hij heeft je eigen gratis Hugging Face-account nodig en een leestoken dat je zelf invoert. Het token staat in de map van de helper op je computer, wordt alleen gebruikt om met Hugging Face te praten en kan worden verwijderd met forget-token. De zin waarmee je een beweging beschrijft, wordt op je eigen computer verwerkt. Deze diensten hebben hun eigen privacybeleid.

Deze website

  • Geen cookies, geen tracking, geen analyse, geen reclame. De pagina's laden geen lettertypen, scripts of afbeeldingen van andere sites.
  • Je taalkeuze en je keuze voor licht of donker worden bewaard in de lokale opslag van je browser op je eigen apparaat (pinglymotion-lang en pinglymotion-theme). Ze worden nooit naar iemand gestuurd. Wis de sitegegevens van je browser om ze te verwijderen.
  • De website wordt gehost door GitHub Pages. GitHub kan bezoekersgegevens zoals IP-adressen verwerken in zijn serverlogs; zie de privacyverklaring van GitHub.

GitHub

De repository, issues en pull requests staan op GitHub en zijn openbaar. Schrijf daar geen persoonlijke gegevens (namen, accountnamen, e-mailadressen of schermafbeeldingen waarop die te zien zijn). Voor je GitHub-account geldt de privacyverklaring van GitHub.

AVG en contact

Het project streeft ernaar de AVG te volgen. De aanpak is dataminimalisatie: het verzamelt niets, dus er zijn bij het project geen persoonsgegevens om in te zien, te corrigeren of te verwijderen. Voor vragen over privacy kun je een issue openen op GitHub. Issues zijn openbaar, dus stel je vraag zonder persoonlijke gegevens.
