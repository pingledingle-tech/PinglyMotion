# Work board

The shared table that used to be here is gone: it made almost every pull
request conflict with `main`. Every job now has its own small file in
`docs/work/`.

- How it works and a template: [`docs/work/README.md`](work/README.md)
- Jobs that finished before the change: [`docs/work/HISTORY.md`](work/HISTORY.md)
- See all jobs: `python3 tools/work.py list`
