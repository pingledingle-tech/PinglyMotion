Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Windows downloads are signed with free code signing provided by SignPath.io, certificate by SignPath Foundation, once the application is approved. Until then, Windows downloads are not signed.

What is signed

Only the Windows program files built by the Release workflow (.github/workflows/release.yml) from the public repository, for a release tag, are signed. Nothing built by hand, no pull request build and no nightly build is signed. The Linux AppImage is not covered by this certificate; every release has SHA-256 checksums and build provenance attestations.

Team roles

  • Committers and reviewers: the project owner, through the GitHub account pingledingle-tech. Contributors send pull requests to the public repository; the main branch only accepts changes through pull requests with passing checks.
  • Approvers: the project owner, through the same GitHub account (pingledingle-tech).

Every release needs manual approval before it is signed. The project owner approves each signing request; there is no automatic approval.

How a release is built and signed

  • The builds are made by GitHub Actions from the public repository. The release tag is created by a person, not by the workflow.
  • The Release workflow first runs the full checks (build and tests, sanitizers, CodeQL, fuzzing). A release is only published when they pass.
  • No manual builds are signed.

Security

Multi-factor authentication is used on the GitHub account and on the SignPath account of the project owner.

Privacy policy

See the privacy policy. In short: PinglyMotion collects no personal data and sends no telemetry. The program's one automatic network use is an update check that asks GitHub's public API for the latest release version; it can be switched off. Because of that check, this page does not use the general statement that a program never transfers information to other networked systems. The details are on the privacy page.

Open source and reports

PinglyMotion is open source under the GNU General Public License (see LICENSE). To report a suspected misuse of the signing certificate or a security problem, use the private route in the security policy.
