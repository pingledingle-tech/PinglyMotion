# Scripts

One folder per product, one folder per part (prim) inside it, one `.lsl` file per script. `cuffs_lock/` is a small working example (a HUD in `Root` and a cuff in `Cuff`); its scenario is `scenarios/cuffs_lock.rlvtest`. Start a new product by copying `template/script.lsl`.

The other two products: `cuff_set/` is the cuff set of the program's examples (four cuffs with chains). `relay_trap/` is a trap in `Root` and a small relay in `Relay`.
