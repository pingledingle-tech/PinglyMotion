# Avatar bodies

The 3D view shows one of two open source bodies for a female figure, chosen under **Options > Body**:

- `ruth2/`: Ruth2 v4, the default body (AGPL-3.0-or-later mesh, with its credits and licence texts).
- `max/`: Max ("Maxine"), an optional second body (CC BY 4.0).

A male figure always shows a third body, with no menu entry:

- `roth2/`: Roth2 v2, the male sibling of Ruth2 (AGPL-3.0-or-later mesh, with its credits and licence texts). If it cannot be read, the male figure is the chosen body with the male skeleton scaling.

All are PinglyMotion mesh files (`.pmm`) converted from the upstream Collada files, see the README and the licence files in each folder. Keep each folder together: a mesh file must not be passed on without the licence files next to it.

The Second Life system avatar (the Linden `.llm` meshes) was removed on 19 November 2026 (issue 15).
